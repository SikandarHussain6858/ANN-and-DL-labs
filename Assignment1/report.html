8.3 Mathematical Explanation of Failure & Repair

  1. Mathematical Mechanism of Failure: The pre-activation of hidden neuron $j$ for input sample $x$ is: $$z_j^{(1)} = w_j^{(1)} x + b_j^{(1)}$$ Because inputs satisfy $\|x\| \lesssim 2.0$ and weights are sampled from a small Gaussian distribution ($\sigma = 0.1$), the linear product $|w_j^{(1)} x| \lesssim 0.2$. With $b_j^{(1)} = -3.0$: $$z_j^{(1)} \approx 0.2 - 3.0 = -2.8 < 0 \quad \forall x \in \mathcal{D}$$ Consequently, the forward ReLU activation evaluates to zero for every single data point: $$a_j^{(1)} = \max(0, z_j^{(1)}) = 0 \quad \forall x \in \mathcal{D}$$ During backward propagation, the local derivative of the ReLU function is: $$\text{ReLU}'(z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z \le 0 \end{cases}$$ Since $z_j^{(1)} < 0$ globally, $\text{ReLU}'(Z_j^{(1)}) = \mathbf{0}$. The pre-activation gradient becomes: $$dZ^{(1)} = dA^{(1)} \odot \text{ReLU}'(Z^{(1)}) = dA^{(1)} \odot \mathbf{0} = \mathbf{0}$$ Substituting into parameter gradient equations: $$dW^{(1)} = \frac{1}{m} dZ^{(1)} X^T = \mathbf{0}, \quad db^{(1)} = \frac{1}{m} \sum dZ^{(1)} = \mathbf{0}$$ Under gradient descent update rules: $$W^{(1)} \leftarrow W^{(1)} - \eta (\mathbf{0}) = W^{(1)}, \quad b^{(1)} \leftarrow b^{(1)} - \eta (\mathbf{0}) = b^{(1)}$$ The hidden layer weights and biases remain permanently frozen for all epochs. The network is locked in a zero-gradient dead state, unable to learn any non-linear features, resulting in flat loss ($0.6931 = \ln 2$) and chance accuracy ($50.00\%$).
  2. Mathematical Mechanism of Repair: By setting $b_j^{(1)} = 0.0$, the pre-activations become $z_j^{(1)} = w_j^{(1)} x$. Because the initial weights have zero mean, approximately 50% of the training points yield positive pre-activations ($z_j^{(1)} > 0$). For these points, $\text{ReLU}'(z_j^{(1)}) = 1.0$, which yields non-zero gradients: $$dZ^{(1)} = dA^{(1)} \odot \mathbf{1} \ne \mathbf{0} \implies dW^{(1)} \ne \mathbf{0}$$ This immediately unlocks backpropagation through the hidden layer, allowing gradient descent to actively shape the hidden feature space and driving accuracy up to 88.00%.
